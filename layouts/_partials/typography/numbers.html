{{- $prose := .text -}} {{- $lang := .lang -}} {{- $space := .space -}} {{- $units := `₽|€|\$|°C|°F|кг|мг|г|км|см|мм|м²|м³|м|мл|л|мс|мин|ч|с|КБ|МБ|ГБ|ТБ|кВт|Вт|Гц|МГц|kg|mg|g|km|cm|mm|m²|m³|m|ml|ms|min|KB|MB|GB|TB|kB|kW|W|Hz|MHz|px` -}} {{- /* Existing digit groups only: years and unformatted IDs are not regrouped. */ -}} {{- $numbers := slice -}} {{- $groups := printf `(?s)(.*?)([\p{L}\p{N}_]+(?:%s[0-9]{3})+(?:[.,][0-9]+)?[\p{L}\p{N}_]*|$)` $space -}} {{- range findRESubmatch $groups $prose -}} {{- $number := index . 2 -}} {{- if findRE (printf `^[0-9]{1,3}(?:%s[0-9]{3})+(?:[.,][0-9]+)?$` $space) $number -}} {{- $number = replaceRE $space "\u202f" $number -}} {{- end -}} {{- $numbers = $numbers | append (index . 1) $number -}} {{- end -}} {{- $prose = delimit $numbers "" -}} {{- /* Match whole candidates, including word prefixes/suffixes, before validating. This leaves model16px and 10MBps intact and handles adjacent measurements without consuming their shared boundary. */ -}} {{- $measurements := slice -}} {{- $candidates := printf `(?s)(.*?)([\p{L}\p{N}_]*[0-9][\p{L}\p{N}_]*(?:[.,][0-9]+)?%s*(?:%s|[%%‰])[\p{L}\p{N}_²³]*|$)` $space $units -}} {{- range findRESubmatch $candidates $prose -}} {{- $measurement := index . 2 -}} {{- $measurement = replaceRE (printf `^([0-9]+(?:[.,][0-9]+)?)%s*(%s)$` $space $units) "$1\u00a0$2" $measurement -}} {{- $percentSpace := "" -}} {{- if eq $lang "ru" -}}{{- $percentSpace = "\u00a0" -}}{{- end -}} {{- $measurement = replaceRE (printf `^([0-9]+(?:[.,][0-9]+)?)%s*([%%‰])$` $space) (printf "$1%s$2" $percentSpace) $measurement -}} {{- $measurements = $measurements | append (index . 1) $measurement -}} {{- end -}} {{- $prose = delimit $measurements "" -}} {{- return $prose -}}

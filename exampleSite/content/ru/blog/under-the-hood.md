Mini разделяет общую типографику, компоновку страницы и поведение браузера.

## Локальные ресурсы

CSS, JavaScript, Inter, KaTeX и ресурсы кнопок шеринга загружаются с домена сайта. Для обычной сборки Hugo установка npm не нужна. Опциональные диаграммы Mermaid используют закрепленную CDN-версию, если сайт не предоставил локальный пакет. Настроенная аналитика, виджеты Telegram и действия шеринга могут обращаться к своим сервисам.

## Условная загрузка

| Возможность | Когда загружается |
| --- | --- |
| Общие CSS и JavaScript темы | На каждой странице; Hugo минифицирует файлы и добавляет хеш в адрес |
| KaTeX | На страницах с `math = true` |
| Mermaid | При приближении к диаграммам на страницах с `mermaid = true` |
| Likely | В статьях с включенным шерингом |
| Комментарии Telegram | При приближении к комментариям, если заданы канал и ID сообщения |

Локальный ESM-пакет Mermaid может загружать только нужные типы диаграмм. При ошибке загрузки исходный текст остается доступным. Объем передаваемых данных зависит от контента, включенных возможностей и кеша браузера.

## Шрифт Inter

Тема содержит четыре WOFF2-начертания с латиницей и кириллицей:

- **300** — основной текст
- **300 italic** — курсив
- **500** — средний акцент и выделенные ссылки
- **600** — заголовки и жирный текст

Начертания 300 и 600 предзагружаются. Остальные загружаются при использовании. Лицензия шрифта хранится рядом с файлами.

## Render Hooks

**Изображения** (`render-image.html`) получают отложенную загрузку и асинхронное декодирование. Для локальных растровых файлов добавляются исходные размеры, резервирующие место. В HTML-изображениях размеры нужно указывать вручную; внешние изображения при сборке не скачиваются.

**Ссылки** (`render-link.html`) открывают внешние URL в новой вкладке с `rel="noopener noreferrer"`. Внутренние ссылки ведут на страницу текущего языка, если перевод существует; `localizeLinks = false` отключает это поведение.

**Заголовки** (`render-heading.html`) сохраняют ID и дополнительные классы. Заголовки H2 и H3 получают копируемую ссылку на раздел, если не указан класс `.no-anchor`.

## Архитектура CSS

- `assets/css/beauty.css` — сгенерированная и закрепленная основа Beauty.css: нативная типографика и общие оформительские классы.
- `assets/css/main.css` — настройки публичных токенов, шрифты, компоновка страницы и компоненты темы.

Hugo Pipes объединяет их в один минифицированный файл с хешем в адресе. Общий браузерный скрипт кешируется между языковыми версиями; переводы интерфейса приходят из HTML. Сайту не нужен отдельный сборщик или JavaScript-фреймворк.

Настраивайте токены в стилях сайта вместо копирования общей типографики:

```css
:root {
  --color-link: #0060a0;
  --color-accent: #b73700;
}
```

`custom_head.html` и `custom_body.html` — точки расширения, а не исходники стилей или скриптов темы. Beauty обновляется через скрипт темы с проверенным коммитом и контрольной суммой.

## Темная тема

Небольшой скрипт определяет сохраненную или системную тему до загрузки стилей. Переключатель в подвале сохраняет явный выбор в `localStorage`; до этого действуют изменения системной темы. Без JavaScript CSS тоже учитывает системную палитру.

## Метаданные и производительность

Общие шаблоны создают канонические URL, социальные метатеги, структурированные данные, ссылки на переводы и ленты. Настройки страницы управляют индексацией и дополнительными возможностями.

Измеряйте собранный сайт с реальным контентом и пустым кешем браузера. Размеры изображений, условная загрузка и кеширование уменьшают лишнюю работу, но тема не гарантирует фиксированный вес страницы, работу офлайн или оценку Lighthouse.

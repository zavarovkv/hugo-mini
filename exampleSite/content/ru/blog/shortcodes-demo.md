Mini включает шорткоды и CSS-классы для контента, который выходит за рамки стандартного Markdown.

## Caption

Шорткод `caption` добавляет стилизованную подпись — курсивную, выровненную вправо, мелким шрифтом. Используйте после изображений или блоков кода:

```markdown
![Фото](/path/to/image.png)
{{</* caption */>}}Рисунок 1 — описание изображения{{</* /caption */>}}
```

{{< caption >}}Рисунок 1 — разместите изображение над этой подписью{{< /caption >}}

## Plug (Разделитель секций)

Шорткод `plug` вставляет декоративный разделитель «* * *» — удобно для разделения секций в длинном посте:

```markdown
{{</* plug */>}}
```

{{< plug >}}

## Выносные цитаты

Используйте HTML-элемент `<q>` для выделенных цитат. Требует `unsafe = true` в конфиге markup Hugo (уже включено в этом примере):

```html
<q>Текст вашей цитаты.</q>
```

<q>Хорошая тема для блога должна быть невидимой. Читатель должен видеть контент, а не дизайн.</q>

## Underline

CSS-класс `.underline` создает декоративное SVG-подчеркивание — подходит для выделения ключевых фраз:

```html
<span class="underline">выделенный текст</span>
```

<span class="underline">Этот текст имеет декоративное подчеркивание</span> — хорошо работает для акцента, который заметнее курсива, но мягче жирного.

## Button

CSS-класс `.button` создает стилизованную кнопку призыва к действию с градиентным фоном:

```html
<a href="/ru/blog/" class="button">Читать статьи</a>
```

<a href="/ru/blog/" class="button">Читать статьи</a>

## Комбинирование элементов

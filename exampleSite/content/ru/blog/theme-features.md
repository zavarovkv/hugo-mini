Помимо Markdown и шорткодов, Mini включает возможности, которые работают через конфигурацию — без изменений в коде.

## Темная тема

Mini определяет цветовую схему системы при первом визите. Переключатель в подвале позволяет читателям сменить тему вручную. Выбор сохраняется в `localStorage`.

Темная тема автоматически адаптирует:

- Цвета текста и фона
- Цвета ссылок и акцентов
- Подсветку блоков кода
- Цвета диаграмм Mermaid
- Аватар (показывает hover-вариант в темной теме)

## Категории

Посты можно группировать по категориям через front matter:

```toml
categories = ["getting-started"]
```

На странице списка блога сверху появляются кнопки категорий. Клик по категории мгновенно фильтрует посты — без перезагрузки страницы, на JavaScript.

## Бейдж «New»

Посты новее настраиваемого порога (по умолчанию 30 дней) автоматически получают красный бейдж «New» на странице списка. Настройте порог в `config.toml`:

```toml
[params]
  newPostDays = 30
```

## Социальный шеринг

Mini включает библиотеку [Likely](https://github.com/nicothin/likely) для кнопок шеринга. Кнопки появляются внизу каждого поста — Telegram, Twitter, Facebook, VK, LinkedIn. Отключить:

```toml
[params]
  socialSharing = false
```

## Поведение внешних ссылок

Все внешние ссылки в контенте постов автоматически открываются в новой вкладке с `rel="noopener noreferrer"`. Это обрабатывается render hook в `layouts/_default/_markup/render-link.html` — без JavaScript.

## Интеграция с Telegram

Mini имеет встроенную поддержку Telegram. Добавьте канал в `config.toml`:

```toml
[params]
  telegramChannel = "your_channel"
  telegramCTATitle = "Мой канал"
  telegramCTADescription = "Подписывайтесь"
```

Это включает:

- CTA-блок под каждым постом с приглашением подписаться
- Комментарии через виджет Telegram (для каждого поста, через `telegram_post` в front matter)

## Мультиязычность

Mini поддерживает два языка из коробки: английский и русский. Переключатель языка появляется в подвале, когда у страницы есть перевод. Настройте языки в `config.toml`:

```toml
[languages]
  [languages.en]
    weight = 1
    contentDir = "content/en"
  [languages.ru]
    weight = 2
    contentDir = "content/ru"
```

## Скрытые посты

Установите `hidden = true` в front matter, чтобы исключить пост из списка блога, сохранив доступ по прямой ссылке — удобно для черновиков, которыми делитесь с рецензентами.

```toml
+++
title = "Секретный пост"
hidden = true
+++
```

## Мобильная навигация

На узких экранах навигация сворачивается в полноэкранное меню-оверлей с гамбургер-кнопкой. Без внешних библиотек — чистый CSS и минимум JavaScript.

Помимо Markdown и шорткодов, Mini включает возможности, которые работают через конфигурацию — без изменений в коде.

## Темная тема

Mini определяет цветовую схему системы при первом визите. Переключатель в подвале позволяет читателям сменить тему вручную. Выбор сохраняется в `localStorage`.

Темная тема автоматически адаптирует:

- Цвета текста и фона
- Цвета ссылок и акцентов
- Подсветку блоков кода
- Цвета диаграмм Mermaid
- Аватар (показывает hover-вариант в темной теме)

## Категории

Посты можно группировать по категориям через front matter:

```toml
categories = ["getting-started"]
```

Список статей сгруппирован под заголовками категорий: две колонки на десктопе и одна на мобильном. Hugo формирует группы и порядок статей без фильтрации на стороне браузера.

## Бейдж «New»

Посты новее настраиваемого порога (по умолчанию 30 дней) автоматически получают красный бейдж «New» на странице списка. Настройте порог в `config.toml`:

```toml
[params]
  newPostDays = 30
```

## Социальный шеринг

Mini включает библиотеку [Likely](https://github.com/nicothin/likely) для кнопок шеринга. Кнопки появляются внизу каждого поста — Telegram, Twitter, Facebook, VK, LinkedIn. Отключить:

```toml
[params]
  socialSharing = false
```

## Поведение внешних ссылок

Все внешние ссылки в контенте постов автоматически открываются в новой вкладке с `rel="noopener noreferrer"`. Это обрабатывается render hook в `layouts/_markup/render-link.html` — без JavaScript.

## Интеграция с Telegram

В Mini две Telegram-фичи, которые работают поверх связки `telegramChannel` + `telegram_post`: виджет комментариев Discussion и счетчики реакций и просмотров, обновляемые при сборке рядом с датой поста. Полный разбор — в отдельном посте [«Интеграция с Telegram»](/telegram-integration/).

## Мультиязычность

Mini поддерживает два языка из коробки: английский и русский. Переключатель языка появляется в подвале, когда у страницы есть перевод. Настройте языки в `config.toml`:

```toml
[languages]
  [languages.en]
    weight = 1
    contentDir = "content/en"
  [languages.ru]
    weight = 2
    contentDir = "content/ru"
```

## Скрытые посты

Установите `hidden = true`, чтобы исключить пост из списков и лент, сохранив публичный URL, запись в sitemap и индексацию. Для неопубликованного материала используйте `draft = true`: `hidden` не ограничивает доступ.

```toml
+++
title = "Пост вне списка"
hidden = true
+++
```

## Закрепленные посты

Установите `pinned = true` в front matter, чтобы поднять пост наверх его категории на странице списка блога. Несколько закрепленных постов внутри одной категории сохраняют обратный хронологический порядок между собой; остальные посты идут ниже также в обратном хронологическом порядке. Этот пост сам использует фичу — он стоит вверху `getting-started` независимо от даты.

```toml
+++
title = "Прочитайте это первым"
pinned = true
+++
```

Никакого визуального маркера — только порядок. Это держит список чистым.

## Последние статьи

Блок последних статей обновляется автоматически. На широком экране он располагается в правом поле и прокручивается вместе со страницей; на мобильном остается внизу статьи.

```toml
[params]
  recentSidebarCount = 8
```

Текущая статья и посты с `hidden = true` не попадают в блок. Значение `0` отключает его.

## Якорные ссылки на заголовках

Markdown-заголовки `##` и `###` получают кликабельную иконку-ссылку (в стиле блога Telegram). На десктопе иконка появляется в левом поле при наведении на заголовок. На мобильном иконка сначала скрыта: нажатие на заголовок показывает ее, а нажатие на иконку копирует URL и переходит к разделу. Если буфер обмена недоступен, обычная якорная ссылка продолжает работать.

Реализовано через render hook `_markup/render-heading.html` + минимум JS — без внешних зависимостей. Важно: hook срабатывает только на markdown-заголовки, а не на сырой HTML `<h2>...</h2>`.

## Privacy-аналитика

Помимо Yandex.Metrika и Google Analytics, Mini из коробки поддерживает две приватные cookieless-опции:

```toml
[params]
  plausibleDomain = "example.com"                       # Plausible
  umamiWebsiteId  = "00000000-0000-0000-0000-000000000000"  # Umami
```

Оба грузятся через `<script defer>`, не блокируя first paint. Для self-hosted инстансов переопредели script src через `plausibleSrc` / `umamiSrc`. Все четыре аналитические интеграции могут работать параллельно; каждая рендерится только если ее обязательный параметр задан.

## Пасхалка в консоли

Установи `consoleYoda = true` в `[params]`, чтобы напечатать встроенный ASCII-арт Йоды в консоли браузера на главной странице:

```toml
[params]
  consoleYoda = true
```

Для своего арта используй `consoleArt` с TOML triple-строкой — он имеет приоритет над `consoleYoda`, если заданы оба.

## Иконки в навигации

К любому пункту меню можно добавить инлайн-SVG иконку через `params.icon`. Встроенная иконка: `telegram` (бумажный самолетик). На десктопе иконка появляется перед текстом с упругой анимацией при наведении; на мобильном — после текста, чуть крупнее.

```toml
[[languages.ru.menu.main]]
  identifier = "telegram"
  name       = "Подписаться"
  url        = "https://t.me/your_channel"
  weight     = 3
  [languages.ru.menu.main.params]
    icon = "telegram"
```

## Кнопка «Наверх»

На широких экранах при наведении на левое поле появляется надпись «Наверх». Клик в любом месте левого поля прокручивает страницу наверх — по аналогии с блогом Telegram. Кнопка появляется только после прокрутки на 400px и только когда viewport достаточно широкий. Значение `backToTop = false` в параметрах страницы или сайта отключает кнопку.

## Мобильная навигация

На узких экранах навигация сворачивается в полноэкранное меню-оверлей с гамбургер-кнопкой. При инициализации меню скрыто. Escape, выбор ссылки или выход фокуса закрывают его; на широком экране возвращается обычная навигация. Без JavaScript ссылки остаются видимыми.

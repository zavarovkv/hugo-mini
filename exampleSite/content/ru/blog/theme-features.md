Помимо Markdown и шорткодов, Mini включает возможности, которые работают через конфигурацию — без изменений в коде.

## Темная тема

Mini определяет цветовую схему системы при первом визите. Переключатель в подвале позволяет читателям сменить тему вручную. Выбор сохраняется в `localStorage`.

Темная тема автоматически адаптирует:

- Цвета текста и фона
- Цвета ссылок и акцентов
- Подсветку блоков кода
- Цвета диаграмм Mermaid
- Аватар (показывает hover-вариант в темной теме)

## Категории

Посты можно группировать по категориям через front matter:

```toml
categories = ["getting-started"]
```

На странице списка блога сверху появляются кнопки категорий. Клик по категории мгновенно фильтрует посты — без перезагрузки страницы, на JavaScript.

## Бейдж «New»

Посты новее настраиваемого порога (по умолчанию 30 дней) автоматически получают красный бейдж «New» на странице списка. Настройте порог в `config.toml`:

```toml
[params]
  newPostDays = 30
```

## Социальный шеринг

Mini включает библиотеку [Likely](https://github.com/nicothin/likely) для кнопок шеринга. Кнопки появляются внизу каждого поста — Telegram, Twitter, Facebook, VK, LinkedIn. Отключить:

```toml
[params]
  socialSharing = false
```

## Поведение внешних ссылок

Все внешние ссылки в контенте постов автоматически открываются в новой вкладке с `rel="noopener noreferrer"`. Это обрабатывается render hook в `layouts/_default/_markup/render-link.html` — без JavaScript.

## Интеграция с Telegram

В Mini две Telegram-фичи, которые работают поверх связки `telegramChannel` + `telegram_post`: виджет комментариев Discussion и живые счетчики реакций/просмотров рядом с датой поста. Полный разбор — в отдельном посте [«Интеграция с Telegram»](/telegram-integration/).

## Мультиязычность

Mini поддерживает два языка из коробки: английский и русский. Переключатель языка появляется в подвале, когда у страницы есть перевод. Настройте языки в `config.toml`:

```toml
[languages]
  [languages.en]
    weight = 1
    contentDir = "content/en"
  [languages.ru]
    weight = 2
    contentDir = "content/ru"
```

## Скрытые посты

Установите `hidden = true` в front matter, чтобы исключить пост из списка блога, сохранив доступ по прямой ссылке — удобно для черновиков, которыми делитесь с рецензентами.

```toml
+++
title = "Секретный пост"
hidden = true
+++
```

## Закреплённые посты

Установите `pinned = true` в front matter, чтобы поднять пост наверх его категории на странице списка блога. Несколько закреплённых постов внутри одной категории сохраняют обратный хронологический порядок между собой; остальные посты идут ниже также в обратном хронологическом порядке. Этот пост сам использует фичу — он стоит вверху `getting-started` независимо от даты.

```toml
+++
title = "Прочитайте это первым"
pinned = true
+++
```

Никакого визуального маркера — только порядок. Это держит список чистым.

## Популярное

Курируемый блок «Популярное» внизу каждого поста. Список задаётся автором вручную — не алгоритмически — в `config.toml`:

```toml
[params]
  popularPosts = [
    "theme-features",
    "under-the-hood",
    "hello-world",
    "math-demo",
  ]
```

Slug'и указываются относительно секции `blog/` и разрешаются под текущий язык через Hugo `site.GetPage` — RU-страницы показывают RU-популярное, EN-страницы показывают EN-популярное. Несуществующие или переименованные slug'и молча пропускаются, так что временно битые записи не ломают сборку.

Визуальный стиль позаимствован у движка Эгея Ильи Бирмана и адаптирован к теме: заголовок использует тот же `.posts-group-title` что и заголовки категорий на странице блога, список переиспользует `.blog-posts`, CSS `column-count: 2` разбивает его на две визуальные колонки на десктопе (одна на мобиле), а дата публикации прячется в `title`-атрибуте как hover-tooltip — блок остаётся компактным без потери метаданных.

Прямо сейчас ты на него смотришь — прокрути вниз этого поста.

## Якорные ссылки на заголовках

Markdown-заголовки `##` и `###` получают кликабельный `#` рядом при наведении. Клик копирует URL секции в буфер обмена с краткой обратной связью. Маркер уменьшен до размера body-текста и использует тот же нейтрально-серый цвет, что и иконки social/theme/lang переключателей в покое.

Реализовано через render hook `_markup/render-heading.html` + минимум JS — без внешних зависимостей. Важно: hook срабатывает только на markdown-заголовки, а не на сырой HTML `<h2>...</h2>`.

## Privacy-аналитика

Помимо Yandex.Metrika и Google Analytics, Mini из коробки поддерживает две приватные cookieless-опции:

```toml
[params]
  plausibleDomain = "example.com"                       # Plausible
  umamiWebsiteId  = "00000000-0000-0000-0000-000000000000"  # Umami
```

Оба грузятся через `<script defer>`, не блокируя first paint. Для self-hosted инстансов переопредели script src через `plausibleSrc` / `umamiSrc`. Все четыре аналитические интеграции могут работать параллельно; каждая рендерится только если её обязательный параметр задан.

## Пасхалка в консоли

Установи `consoleYoda = true` в `[params]`, чтобы напечатать встроенный ASCII-арт Йоды в консоли браузера на главной странице:

```toml
[params]
  consoleYoda = true
```

Для своего арта используй `consoleArt` с TOML triple-строкой — он имеет приоритет над `consoleYoda`, если заданы оба.

## Иконки в навигации

К любому пункту меню можно добавить инлайн-SVG иконку через `params.icon`. Встроенная иконка: `telegram` (бумажный самолетик). На десктопе иконка появляется перед текстом с упругой анимацией при наведении; на мобильном — после текста, чуть крупнее.

```toml
[[languages.ru.menu.main]]
  identifier = "telegram"
  name       = "Подписаться"
  url        = "https://t.me/your_channel"
  weight     = 3
  [languages.ru.menu.main.params]
    icon = "telegram"
```

## Мобильная навигация

На узких экранах навигация сворачивается в полноэкранное меню-оверлей с гамбургер-кнопкой. Без внешних библиотек — чистый CSS и минимум JavaScript.

Mini рендерит весь стандартный Markdown с чистой, читаемой типографикой на шрифте [Inter](https://rsms.me/inter/) — шрифты хостятся локально, без CDN.

## Заголовки

## Форматирование текста

Основной текст набран начертанием 300 для комфортного чтения. **Жирный текст** использует начертание 600 и цвет заголовков для акцента. *Курсивный текст* добавляет легкий визуальный сдвиг. Можно комбинировать **_жирный и курсив_** при необходимости.

Инлайновый `код` рендерится моноширинным шрифтом с легким фоном — удобно для упоминания `config.toml` или `hugo server`.

## Ссылки

Внутренние ссылки вроде [Статьи](/ru/blog/) работают обычно. Внешние ссылки вроде [документация Hugo](https://gohugo.io/documentation/) автоматически открываются в новой вкладке с `rel="noopener noreferrer"` — благодаря встроенному render hook. Никакой настройки не нужно.

## Списки

Ненумерованные списки:

- Локальный шрифт Inter (начертания 200–700)
- Темная тема с определением системных настроек
- Мультиязычность с переключателем языка
- Адаптивная верстка mobile-first

Нумерованные списки получают жирные маркеры для удобства сканирования:

1. Создайте контент в директории `content/`
2. Настройте тему в `config.toml`
3. Запустите `hugo server` для локального превью
4. Разверните с помощью `hugo --minify`

Вложенные списки тоже работают:

- Типографика
  - Заголовки с прогрессивной шкалой
  - Комфортное начертание для чтения
  - Моноширинные блоки кода
- Возможности
  - Математические формулы KaTeX
  - Диаграммы Mermaid
  - Кастомные шорткоды

## Блоки кода

Подсветка синтаксиса работает из коробки. Цвета автоматически адаптируются к темной теме.

```go
package main

import "fmt"

func main() {
    fmt.Println("Привет из Mini!")
}
```

```css
:root {
  --color-primary: #0060a0;
  --color-accent: #d04000;
}
```

## Изображения

Изображения загружаются лениво с `loading="lazy"` и `decoding="async"` через render hook. Просто используйте стандартный синтаксис Markdown:

```markdown
![Описание](/path/to/image.png)
```

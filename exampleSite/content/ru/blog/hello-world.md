Mini оформляет обычный Markdown через Beauty.css. По умолчанию используется [Inter](https://rsms.me/inter/); публичное демо показывает отдельный профиль шрифтов. Шрифты загружаются с самого сайта.

## Заголовки

Уровни заголовков различаются размером и межстрочным интервалом; гарнитура и вес зависят от активного профиля шрифтов.

## Форматирование текста

**Жирный текст**, *курсив* и **_их сочетание_** используют активный профиль шрифтов. У встроенного Inter основной текст имеет вес 300, выделенные ссылки — 500, жирный текст — 600.

Встроенный `код` набран моноширинным шрифтом с легким фоном в темной теме: `config.toml`, `hugo server`.

## Ссылки

Внутренние ссылки вроде [Статьи](/ru/blog/) работают обычно. Внешние ссылки вроде [документация Hugo](https://gohugo.io/documentation/) автоматически открываются в новой вкладке с `rel="noopener noreferrer"` — благодаря встроенному render hook. Никакой настройки не нужно.

## Списки

Ненумерованные списки:

- Локальный Inter: обычные начертания 300, 500 и 600 и курсив 300
- Темная тема с определением системных настроек
- Мультиязычность с переключателем языка
- Адаптивная верстка mobile-first

Маркеры нумерованного списка имеют тот же вес, что и окружающий текст:

1. Создайте контент в директории `content/`
2. Настройте тему в `config.toml`
3. Запустите `npm run dev` для демо или стартера с поиском
4. Соберите сайт через `npm run build` и опубликуйте `public/`

Вложенные списки тоже работают:

- Типографика
  - Заголовки с прогрессивной шкалой
  - Комфортное начертание для чтения
  - Моноширинные блоки кода
- Возможности
  - Математические формулы KaTeX
  - Диаграммы Mermaid
  - Кастомные шорткоды

## Блоки кода

Установите `markup.highlight.noClasses = false`, чтобы подсветка следовала цветовой теме. В конфигурации демо этот параметр уже задан.

```go
package main

import "fmt"

func main() {
    fmt.Println("Привет из Mini!")
}
```

```css

  --color-accent: #d04000;
```

## Изображения

Изображения загружаются лениво с `loading="lazy"` и `decoding="async"` через render hook. Просто используйте стандартный синтаксис Markdown:

```markdown
![Описание](/path/to/image.png)
```

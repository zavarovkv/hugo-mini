Добро пожаловать в **Mini** — минималистичную тему Hugo для авторов, которым нужен удобный интерфейс для чтения. Теме не нужен JavaScript-фреймворк или отдельный сборщик.

Шрифт Inter, общие CSS и JavaScript и сгенерированные изображения для шеринга хранятся локально. Дополнительные интеграции, включая Telegram, аналитику и CDN-версию Mermaid, подключаются отдельно.

<h3 class="posts-group-title">С чего начать</h3>

- [Возможности темы](/ru/theme-features/) — темная тема, категории, закрепленные посты, сайдбар с последними статьями и все остальное через `config.toml`
- [Hello World](/ru/hello-world/) — классический первый пост, оставлен как шаблон
- [Под капотом](/ru/under-the-hood/) — как устроена тема: архитектура CSS, render-хуки, Hugo Pipes
- [Интеграция с Telegram](/ru/telegram-integration/) — комментарии через Discussion, реакции, количество просмотров

<h3 class="posts-group-title">Демо-посты</h3>

- [Математические формулы](/ru/math-demo/) — рендеринг через KaTeX, подключается на отдельной странице
- [Диаграммы Mermaid](/ru/mermaid-demo/) — flowchart, sequence, state, ER
- [Шорткоды](/ru/shortcodes-demo/) — `caption`, `mermaid`, `plug`

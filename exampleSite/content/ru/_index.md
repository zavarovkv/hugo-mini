Добро пожаловать в **Mini** — быструю минималистичную тему для блогов на Hugo. Сделана для авторов, которым нужен чистый и ненавязчивый интерфейс для чтения. Никаких JavaScript-фреймворков, никаких CDN, никаких сборщиков — только Hugo.

Все ресурсы локальные: шрифт Inter, минифицированные CSS и JS, OG-картинки сгенерированные при сборке. Читатели не обращаются к третьим сторонам — и страницы все равно загружаются меньше чем за секунду.

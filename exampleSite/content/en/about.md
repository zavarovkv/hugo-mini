<span class="underline">For readers</span> — this is an example of a standalone page in the Mini theme. Standalone pages live outside the blog section and are perfect for static content like "About", "Contact", or "Services".

<span class="underline">For developers</span> — just create a Markdown file in the content root (outside the `blog/` folder). Hugo will render it using the default single layout. You can link to it from the navigation menu via `config.toml`.

Any standard Markdown and shortcodes work here, just like in blog posts.

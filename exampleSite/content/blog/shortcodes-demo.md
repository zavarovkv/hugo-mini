Mini includes three shortcodes for enhanced content formatting.

## Caption

Add a caption below an image:

![Example](/images/og-default.png)
{{< caption "Figure 1 — image with caption" >}}

## Plug

Insert a decorative section divider:

{{< plug >}}

Content continues after the divider.

## Highlighted Quote

Use the `<q>` HTML element for pull quotes (requires `unsafe = true` in markup config):

<q>The best interface is no interface.</q>

This is a demo post for the **Mini** Hugo theme. It supports all standard Markdown features.

## Features

Mini is designed for personal blogs with a focus on:

1. **Speed** — minimal CSS, self-hosted fonts, no external dependencies
2. **Readability** — clean typography with Inter font
3. **Dark mode** — follows system preference, toggle in footer
4. **Multilingual** — built-in i18n support

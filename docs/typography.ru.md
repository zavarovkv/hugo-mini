# Типографика

[English](typography.md) | Русский

Goldmark обрабатывает знаки препинания Markdown, Hugo Mini исправляет текст при сборке, Beauty.css отвечает за оформление. Без дополнительного JavaScript.

## Правила

| Исходный текст | Результат в RU | Результат в EN |
| --- | --- | --- |
| `"Фильм 'Звездные войны'"` | `«Фильм „Звездные войны“»` | Кавычки Goldmark |
| `«Фильм «Звездные войны»»` | `«Фильм „Звездные войны“»` | Без изменений |
| `«Звездные войны» - классика` | `«Звездные войны» — классика` | Без изменений |
| `в Москве и на улице` | `в Москве и на улице` | Без изменений |
| `из-за, из-под` | `из‑за, из‑под` | Без изменений |
| `т.е., т. д.` | `т. е., т. д.` | Без изменений |
| `сказал бы, он же` | `сказал бы, он же` | Без изменений |
| `и на улице` | `и на улице` | Без изменений |
| `1 000 000` | `1 000 000` | `1 000 000` |
| `3000₽` | `3000 ₽` | `3000 ₽` |
| `16px` | `16 px` | `16 px` |
| `10 %` | `10 %` | `10%` |

- **Кавычки:** внешние `«...»`, вложенные `„...“`. Работает внутри inline-разметки, включая текст ссылок. Апострофы сохраняются.
- **Тире:** Goldmark заменяет `--` → `–`, `---` → `—`; Mini исправляет `слово - слово` в русском тексте. `1 - 2` и `по-настоящему` не меняются.
- **Короткие слова:** `в, к, с, у, о, и, а, на, по, из, от, до, за, во, со, ко, об` связываются со следующим словом длиной от трех букв. Соседние короткие слова образуют группу из трех слов (`и на улице`); длинные цепочки не создаются.
- **Составные предлоги:** дефис в `из‑за` и `из‑под` не переносится.
- **Сокращения:** части `т. е., т. д., т. п., т. к., т. н., т. о.` не разрываются; `т.е.` нормализуется до `т. е.`.
- **Частицы:** `же, ли, ль, бы, б` связываются с предыдущим словом: `он же`, `сказал бы`.
- **Пробелы:** U+202F между группами цифр; U+00A0 перед единицами измерения, процентами и тире в русском тексте, между словами и частицами из примеров выше. Для `из‑за` используется U+2011.

## Где работает

- Основной текст **главной страницы и публикаций** на русском и английском. Исходные Markdown-файлы, заголовки страниц, метаданные и ленты не меняются.
- Код, формулы, Mermaid, HTML-теги и атрибуты, комментарии, URL и пути сохраняются. Слова через HTML-теги не связываются.
- Другие языки дополнительным обработчиком не затрагиваются.

## Как отключить

Для страницы:

```toml
+++
typography = false
+++
```

Для всего сайта:

```toml
[params]
  typography = false
```

`typography = true` на странице переопределяет настройку сайта. Исключение для HTML-фрагмента:

```html
<span data-typography="off">«Фильм «Звездные войны»» - 16px</span>
```

Для HTML нужен `markup.goldmark.renderer.unsafe = true`. Эти настройки управляют **дополнительной обработкой Mini**, но не заменами Goldmark. Они настраиваются через [Goldmark Typographer](https://gohugo.io/configuration/markup/#typographer).

## Оформление

Текст 16 px, максимальная ширина 720 px. Beauty.css задает ритм заголовков, интервалы и переносы; таблицы и код прокручиваются отдельно. См. [настройку темы](customization.md).

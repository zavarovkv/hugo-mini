# Типографика

[English](typography.md) | Русский · [Документация](README.md) · [Справочник оформления](typography-reference.ru.md)

Goldmark обрабатывает пунктуацию Markdown, Mini форматирует текст при сборке,
Beauty.css отвечает за верстку. Исходники сохраняются; браузерный JavaScript текст не переписывает.

## Правила для русского языка

| Что делает | Было | Стало |
| --- | --- | --- |
| Заменяет внешние кавычки на «...» | `"Фильм"` | `«Фильм»` |
| Исправляет вложенные кавычки | `«Фильм «Звездные войны»»` | `«Фильм „Звездные войны“»` |
| Превращает `--` в короткое тире | `слово -- слово` | `слово – слово` |
| Превращает `---` в длинное тире | `слово --- слово` | `слово — слово` |
| Заменяет дефис между словами на тире | `слово - слово` | `слово — слово` |
| Заменяет три точки на многоточие | `Подожди...` | `Подожди…` |
| Привязывает короткое слово к следующему | `в Москве` | `в Москве` |
| Объединяет два коротких слова со словом из 3–12 букв | `и на улице` | `и на улице` |
| Делает дефис в предлогах неразрывным | `из-за, из-под` | `из‑за, из‑под` |
| Не разрывает части сокращений | `т.е., т. д.` | `т. е., т. д.` |
| Привязывает частицу к предыдущему слову | `он же, сказал бы` | `он же, сказал бы` |
| Не разрывает готовые группы цифр | `1 000 000` | `1 000 000` |
| Добавляет неразрывный пробел перед валютой | `3000₽` | `3000 ₽` |
| Добавляет неразрывный пробел перед единицей | `16px` | `16 px` |
| Добавляет неразрывный пробел перед процентом и промилле | `10 %, 10 ‰` | `10 %, 10 ‰` |

Goldmark обрабатывает исходные кавычки, `--`, `---` и многоточия; Mini уточняет русские кавычки, тире и пробелы при сборке. Короткие слова: `в, к, с, у, о, и, а, на, по, из, от, до, за, во, со, ко, об` (связка со словом от трех букв). Сокращения: `т. е., т. д., т. п., т. к., т. н., т. о.`; частицы: `же, ли, ль, бы, б`.

U+00A0 — неразрывный пробел, U+202F — узкий неразрывный пробел в числах, U+2011 — неразрывный дефис. Правила для английского описаны в [English guide](typography.md).

## Где работает

- Mini обрабатывает текст между HTML-тегами. Правила для чисел применяются к фрагментам с цифрами, вложенность русских кавычек учитывается и по обе стороны строчного тега.
- Дополнительная обработка действует на русский текст главной, публикаций и отдельных страниц, видимые заголовки и ссылки на статьи. Метаданные, ленты и Markdown-исходники сохраняются.
- Код, формулы, Mermaid, HTML-атрибуты и комментарии, URL и пути не меняются. Слова через теги не связываются; неоднозначные диапазоны не угадываются. Кавычки могут охватывать строчную разметку; апострофы в именах сохраняются.
- Английский имеет [свои правила](typography.md#english-rules). Другие языки не получают дополнительную обработку прозы Mini.

## Как отключить

Укажите `typography = false` в параметрах страницы или в таблице `[params]` сайта. Настройка страницы имеет приоритет. Чтобы пропустить один фрагмент вместе с вложенными элементами, добавьте атрибут к его обертке.

```html
<span data-typography="off">«Фильм «Звездные войны»» - 16px</span>
```

HTML требует `markup.goldmark.renderer.unsafe = true`. Эти настройки не отключают
[Goldmark Typographer](https://gohugo.io/configuration/markup/#typographer).
Визуальные правила, например переносы заголовков, имеют собственные CSS-настройки.

## Цитаты и подписи

Задайте `editorialQuotes = true` в `[params]` или front matter страницы и используйте Markdown:

```markdown
> Цитата, которую стоит сохранить.
```

Параметр включает `beauty-quotation quotation-reading` для Markdown-цитат и `callout`.
По умолчанию выключен; `editorialQuotes = false` возвращает обычные цитаты
и оформление `callout` с фоном.

| Содержимое | Результат |
| --- | --- |
| Проза без внешних кавычек | Добавляется выделяемая пара `«…»` по-русски или `“…”` в остальных языках. |
| Готовые кавычки, в том числе внутри выделений и ссылок | Открывающая выносится в поле без второй пары. |
| Конечные знаки | Сохраняются; русская точка идет после закрывающей кавычки. |
| Код, таблицы, вложенные цитаты | Кавычки не добавляются. |
| Явные HTML-фигуры и готовые элементы вынесенных кавычек | Разметка сохраняется. |

Абзацы, списки, ссылки и выделения остаются семантическими. Русские вложенные
кавычки распознаются как символы и HTML-сущности; видимый URL не нарушает соседние
цитаты. Исходники, атрибуты, строчный код и хеши переводов не меняются.

### Добавить автора

Для автора или источника используйте семантическую фигуру:

```html
<figure class="beauty-quotation quotation-reading">
  <blockquote><p><span class="beauty-hanging-open">«</span>Полезная цитата».</p></blockquote>
  <figcaption class="beauty-quotation-attribution">
    <span aria-hidden="true">—</span>
    <span><span class="beauty-quotation-author">Автор</span>, источник</span>
  </figcaption>
</figure>
```

Если источник уже назван перед цитатой, подпись можно опустить. Без
`beauty-quotation-author` она остается равномерно приглушенной. Уберите
`quotation-reading` для более крупного отдельного отзыва. Подписи сохраняют
основной шрифт даже при отдельном [шрифте цитат](fonts.md#a-separate-quotation-family).

Для собственного определения или тезиса используйте `<p class="beauty-lead">…</p>`.
Такой абзац набран крупнее основного текста и на экране совпадает по цвету с буквицей. См. [размеры и интервалы цитат](typography-reference.ru.md#цитаты).

## Кавычки, цифры и дроби

Оба параметра по умолчанию равны `false` и доступны для сайта или страницы:

| Параметр | Область действия и исключения |
| --- | --- |
| `hangingQuotes = true` | Выносит начальные «, “ или ‘ в H1–H3 и обычных абзацах, включая цитаты. Исключает абзацы списков, сносок, таблиц, фигур и врезок. |
| `proseNumerals = true` | Включает минускульные пропорциональные цифры в абзацах верхнего уровня и в тексте цитат, включая `beauty-quotation`. Заголовки, списки, таблицы, подписи и номера сносок сохраняют обычные цифры. |

Вынесенная кавычка сохраняется при копировании и возвращается в строку при печати.
Списки статей и метаданные не меняются. `typography = false` и
`data-typography="off"` отключают обработку; ссылки заголовков учитывают кавычку на узком экране.

Минускульные цифры зависят от OpenType-возможностей шрифта. Для аналитических страниц
задайте `proseNumerals = false`, для отдельного значения —
`<span class="beauty-lining-nums">7/10</span>`.

`{{< fraction "1/3" >}}` оформляет явную дробь: неотрицательные целые числитель
и знаменатель, знаменатель не равен нулю. Beauty уменьшает цифры, сохраняя высоту
строки и копируемый текст. Даты, оценки, URL и формулы автоматически не преобразуются.

## Отметки о публикации статьи

Разместите известную отметку после заключения, перед сносками:

```html
<p class="beauty-note">Статья опубликована в
<a href="https://example.org/article/">названии издания</a>.</p>
```

Примечание прямое, обычной насыщенности, приглушенное, размером `0.875em`; название
издания сохраняет стиль ссылки. Не добавляйте встроенные стили, жирное или курсивное
выделение. Синхронизируйте URL и положение в переводах; слово «впервые» используйте
только при известной хронологии. Для источника изображения есть [подпись](media.md#captions).

## Буквица

Задайте `dropCap = true` во front matter **отдельной статьи**. По умолчанию выключен
и не наследуется из параметров сайта.

- Начните обычным абзацем: предшествующий заголовок, цитата, список или фигура отключают оформление.
- Выбирайте достаточно длинное начало для обтекания; проверяйте каждый язык.
- Предпочитайте простое первое слово: открывающая кавычка тоже увеличится, а оформление слова может подчеркнуть буквицу.
- Примечания, подписи, мелкий текст и абзацы с `data-typography="off"` исключены.

Буквица использует семейство и насыщенность H1, обтекается двумя строками и поднята
на четверть строки. В обеих темах у буквицы легкий оттенок цвета ссылок. Печать и браузеры без
`initial-letter` показывают обычный текст; дополнительные скрипты и шрифты не загружаются.

Для однобуквенного начала, например английских «I» и «A», неразрывный пробел сохраняет
разделение слов при копировании в Chromium; `typography = false` отключает эту поправку.
При смене шрифта см. [переменные буквицы](typography-reference.ru.md#буквица).

## Ссылки в статьях

Внешние Markdown-ссылки открываются в новой вкладке по умолчанию. Задайте `articleLinksNewTab = true` в `[params]` или в параметрах страницы, чтобы так же открывались внутренние ссылки на страницы из текста статьи.

Настройка действует в статьях из `mainSections`. При сборке Hugo добавляет к Markdown-ссылкам `target="_blank"` и `rel="noopener noreferrer"`. Браузер применяет эти атрибуты к ссылкам из HTML и шорткодов. Якоря текущей страницы, сноски, загрузки, ссылки вроде `mailto:`, меню и отдельные страницы сохраняют обычное поведение.

## Сноски и примечания

Используйте нативный Markdown без шорткода:

```markdown
Полезный тезис[^source] может снова ссылаться на ту же сноску[^source].

[^source]: Короткое примечание с источником.
```

Номер в начале сноски возвращает к первому упоминанию в тексте.
Номер виден, даже если сноска начинается с кода, цитаты или списка.

### Примечания на полях компьютера

Включите `sideNotes = true` для сайта или страницы. При достаточном боковом поле
исходные сноски располагаются рядом с первыми ссылками, без расширения колонки
и дублирования ID. Плотные заметки сдвигаются, обходят широкие блоки и резервируют место до футера.

Узкое окно, телефон, печать и режим без JavaScript сохраняют концевые сноски.
На полях скрывается предшествующий заголовок H2–H6. Повторные ссылки ведут к одной заметке. Начальный переход
к сноске уточняется после загрузки шрифтов и изображений, если читатель еще не взаимодействовал со страницей.

### Общая типографика

Маленькие курсивные надстрочные номера сохраняют ссылки и видимый фокус, не увеличивая
строки. Сноски набраны основным шрифтом приглушенного цвета. Строки выровнены по левому краю номера. Размеры, интервалы и адаптер Beauty описаны
в [справочнике сносок и списков](typography-reference.ru.md#сноски-и-списки).

## Оглавление на полях

Включите `articleOutline = true` для сайта или отдельной статьи. Оглавление доступно в статьях с двумя и более видимыми Markdown-заголовками H2. На экранах шириной от 64rem оно появляется, когда заголовок статьи уходит за верхний край. Первая точка ведет к заголовку статьи, римские номера — к разделам. Наведение или фокус показывает название. Линия заполняется по мере чтения. Переход по ссылке плавный, а при настройке уменьшенного движения — мгновенный. Для оглавления нужен JavaScript.

## Прокрутка по заголовку

Включите `headingScroll = true` для сайта или страницы; по умолчанию выключен.

| Действие | Результат |
| --- | --- |
| Нажать H1/H2 | Выровнять на 24 px ниже верха окна и обновить фрагмент URL. |
| Tab, затем Enter/Space | Выбрать и активировать обычную текстовую ссылку. |
| Option/Alt + Down / Up | Следующий / предыдущий H1/H2 относительно позиции чтения, без зацикливания. |
| Нажать H3 | Сохранить обычное копирование ссылки. |

H1 ведет на `#page-title`, H2 сохраняет ID раздела. Между заголовками стрелка вверх возвращает к началу текущего раздела. Кнопки браузера «Назад» и «Вперед» работают с этими переходами. При выделении текста, редактировании или открытом меню и диалоге сочетания клавиш сохраняют обычное поведение.

Для своих шаблонов доступны `data-heading-scroll` (включить H3–H6) и `data-heading-reset` (очистить фрагмент адреса). Класс `.no-anchor` исключает заголовок. При уменьшенной анимации прокрутка мгновенная, а без JavaScript доступны исходные ссылки H2/H3. [Переходы между статьями](content.md#article-keyboard-navigation)

## Оформление

Основная колонка — 720 px; текст 18/28 px на компьютере и 19/29 px на телефоне.

в [справочнике оформления](typography-reference.ru.md#основная-верстка).

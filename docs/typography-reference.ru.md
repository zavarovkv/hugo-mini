# Справочник типографики

[English](typography-reference.md) | Русский · [Документация](README.md) · [Руководство автора](typography.ru.md)

**Для настройки и сопровождения темы.** Здесь собраны правила оформления по умолчанию;
автору не нужно задавать их вручную. Mini отвечает за геометрию страницы и значения
переменных, Beauty.css — за нативные стили текста. Меняйте переменные, не копируйте базовые селекторы.

## Основная верстка

| Элемент | Компьютер | Телефон, до 768 px включительно |
| --- | --- | --- |
| Колонка чтения | До 720 px | Доступная ширина |
| Текст / интерлиньяж | 18/28 px | 19/29 px |
| H1 | 44 px | 32 px |
| H1 главной страницы | 36 px | 32 px |
| Шапка — H1 | 48 px | 40 px |
| H1 — содержание | 32 px | 28 px |
| H2 статьи | Шкала заголовков темы | 24 px |
| Подписи авторов | Шкала подписей темы | 15 px |
| Метаданные статьи | Шкала метаданных темы | 14 px |
| Сноски / интерлиньяж | 15/24 px | 16/25,6 px |
| Обозначение языка | 12 px | 12 px |
| Бейдж новинки | 11 px | 11 px |
| Содержание — футер сайта (`--footer-gap`) | 112 px | 88 px |

Короткие и многострочные заголовки имеют общий ритм. Страница 404 использует тот же
масштаб текста и шапки; ASCII-иллюстрация — отдельный моноширинный размер. Примечания
и подписи изображений масштабируются с текстом статьи; навигация остается компактной.

- Крупные авторские абзацы имеют насыщенность основного текста, заголовки таблиц — насыщенность заголовков. Вопросы интервью оформляйте заголовками Markdown, без пустых `<br>`.
- Названия проектов используют настоящее настроенное жирное начертание (Inter 600); SVG-стрелки имеют собственную толщину.
- Бейджи «Нов.» / «New» стоят на базовой линии: белый жирный текст без разрядки, фон `--color-badge-new`.
- Волнистое подчеркивание использует `--beauty-emphasis-offset: 0.2em`; само оформление принадлежит Beauty.

Видимые заголовки экранируются перед языковой обработкой. `typography = false`
отключает ее и для названий; метаданные, ленты и URL сохраняются. Целые корректные
ISO-даты в ячейках получают `<time>` и остаются на одной строке. Книжные таблицы
сохраняют [локальную прокрутку и минимум 20em](homepage.md#table-layout).

Тематические разделители используют `--beauty-rule-margin: 2rem 1rem`: 32 px до
линии и 16 px после. Разделители строк меню и поиска сохраняют симметричные отступы.

## Заголовки

[Профили шрифтов](fonts.md) меняют семейства и реальные начертания без изменения
геометрии. Отдельное семейство H1 имеет обычную разрядку на компьютере и `-0.01em`
на телефоне. `articleH2UseTitleFont` применяет его к H2 статьи; H3–H6 и заголовки
других страниц сохраняют роли. Доступны переопределения страницы и `useDefaultFonts`.

| Переменная на `body.reading-layout` | По умолчанию | Отключение |
| --- | --- | --- |
| `--beauty-h1-transform` | Сдвиг `-0.025em` на экране при LTR | `none` |
| `--beauty-h2-transform` | Сдвиг `-0.02em` на экране при LTR | `none` |
| `--beauty-h1-hyphens` | `auto` до 360 px, иначе ручные переносы | `manual` |
| `--beauty-h1-hyphen-limit` | Ограничение слова/фрагментов `10 4 4` | Зависит от браузера |

Оптические сдвиги выравнивают края символов, не меняя колонку и ширину строки;
RTL и печать остаются без сдвига. На узком экране переносы используют язык документа
и словарь браузера. Широкие заголовки сохраняют баланс строк, другой текст — свои правила.
Мягкие переносы и скрипты не меняют исходники или копируемый текст.

Эти настройки независимы от обработки пунктуации. Поведение ссылок описано
в [навигации по заголовкам](typography.ru.md#прокрутка-по-заголовку),
индикатор фокуса — в [настройках темы](customization.md#focus-and-controls).

## Цитаты

См. [примеры разметки](typography.ru.md#цитаты-и-подписи).
Все варианты используют общую геометрию и настроенную гарнитуру цитат:

| Свойство | По умолчанию |
| --- | --- |
| Максимальная ширина | 640 px, по краю колонки чтения |
| Отступ сверху / снизу | 24 / 32 px |
| Сверху после `plug` | 16 px |
| Между абзацами | 16 px |
| Отдельный отзыв | 20/30 px на компьютере и телефоне |
| `.quotation-reading` | 18/28 px на компьютере, 19/29 px на телефоне |
| Отступ до подписи / гарнитура | 20 px / основной шрифт |
| Выравнивание подписи | `--beauty-quote-attribution-align: end`, приглушенный цвет |
| Открывающая кавычка | Масштаб 1,4, `--beauty-hanging-gap: 0.08em` |
| Промежуток после тире подписи | `0.125em`; тире рядом с подписью, не в поле |
| Футер после последней цитаты | `--footer-quotation-gap`: 176 px на компьютере, 128 px на телефоне |
| Авторский тезис (`beauty-lead`) | `--beauty-lead-margin-block`: 32 px сверху, 48 px снизу |

Подписи переносятся внутри ширины цитаты; нативные `blockquote footer` и подписи
после прямого `blockquote` тоже выравниваются по конечному краю. Подписи изображений
имеют отдельные роли. Кавычки не увеличивают строку; при печати возвращаются внутрь
в обычном масштабе. Авторские тезисы при печати получают обычные интервалы абзаца.

## Буквица

`beauty-dropcap` использует нативный `::first-letter`. Тема передает семейство
и насыщенность H1, без копии буквы или дополнительного запроса шрифта.

| Переменная | Настройка темы / значение |
| --- | --- |
| `--beauty-dropcap-font` | `--font-title` |
| `--beauty-dropcap-weight` | `--font-weight-title` |
| `--beauty-dropcap-lines` | `2` |
| `--beauty-dropcap-lines-small` | Значение Beauty: `2` |
| `--beauty-dropcap-rise` | `0.25`; `0` для обычной опущенной буквицы |
| `--beauty-dropcap-gap` | Общий интервал Beauty |
| `--beauty-dropcap-margin-block-end` | `-0.3em`; `0`, если нижнему выносному элементу нужно больше места |

Отрицательный нижний отступ не дает короткому элементу буквы, например Ц, сдвинуть
третью строку. Меняется область обтекания, не сама буква. Короткий абзац сохраняет
высоту двух строк. После смены шрифта проверьте зазоры под буквицей и над абзацем.

Стандартный CSS использует верхнее выравнивание и подъем относительно строки,
WebKit с префиксом — нативную базовую линию. Это предотвращает сдвиг на целую строку
в Chromium. Исправления геометрии принадлежат Beauty, лицензированные шрифты — сайту.
При печати и без поддержки браузером остается обычный текст.

## Сноски и списки

| Элемент | Правило |
| --- | --- |
| Ссылка на сноску | Курсивный надстрочный номер, нулевой интерлиньяж, относительный подъем; без `vertical-align: super` |
| Концевая сноска | Приглушенный основной шрифт, висячий номер, без отступа списка; нативные ссылки и фокус |
| Обычный список | Маркер наследует насыщенность; интервал `0.875rem` (14 px); отступ `min(2.5rem, 8%)` |
| Ритм сносок | Отдельные `--beauty-footnote-*`, включая `--beauty-footnote-line-height` |

Стили принадлежат `beauty-footnotes`, `beauty-footnote-ref` и `beauty-footnote-backref`
из Beauty. Адаптер `beauty-compat.html` сопоставляет классы Goldmark, не дублируя CSS
и не переписывая HTML статьи. Формулы и другие надстрочные/подстрочные элементы не меняются.

Боковые примечания дополнительно используют:

| Переменная | По умолчанию |
| --- | --- |
| `--article-sidenote-gap` | 40 px |
| `--article-sidenote-min-width` | 220 px |
| `--article-sidenote-max-width` | 260 px |
| `--article-sidenote-space` | 24 px между заметками и у края окна |

Перед изменениями проверьте [поведение боковых сносок](typography.ru.md#примечания-на-полях-компьютера),
особенно при плотных примечаниях и широких фигурах.

## Ссылки, подписи и колонки

Роли подписей и ограничения широких блоков описаны в [руководстве по медиа](media.md).
`--beauty-caption-*` управляют общим размером и ритмом подписей.

Стрелки проектов и архива используют `link-arrow.html`: один путь, линия толщиной
1 на поле 16, поворот -45° для внешней ссылки. `beauty-link-icon` задает размер
`1em`, выравнивание `-0.125em` и `currentColor`. Подчеркнут и доступен как имя ссылки
только текст; стрелки не добавляют запросов и остановок фокуса.

| Движение | По умолчанию |
| --- | --- |
| Архив | `0.25em` вправо за 300 мс |
| Проект | `0.175em` вправо и вверх за 300 мс |
| Уменьшение движения | Отключено |
| Сенсорный экран | Нет сохраняющейся анимации наведения |

Надписи и верстка неподвижны. Обычные ссылки статей и стрелка диапазона дат
сохраняют свое оформление. Стабильное место для полосы прокрутки не дает обычному
скроллбару сдвигать колонку. Оверлейные полосы не занимают места; в печати резерв отключен.

## Код, таблицы и печать

[Подсветка через классы](configuration.md#syntax-highlighting) дает светлую/темную
палитры с контрастом текста 4,5:1 на обычных и выделенных строках, включая номера.
Встроенная палитра отдельного блока остается ответственностью сайта.

Таблицы сохраняют нативную разметку внутри подписанной области `beauty-scroll`
с клавиатурным фокусом. Прокрутка локальная. ID, классы, выравнивание и семантические
даты сохраняются. При печати колонки фиксированы, текст ячеек переносится без уменьшения текста статьи.

Размеры текста / названия / раздела при печати — 11/22/16 pt независимо от окна;
код монохромный с переносами. Mermaid использует
[нейтральный кеш или читаемый исходник](media.md#diagram-loading-and-printing).
Отдельной кнопки печати и переопределения `window.print` нет.
